# @midika/ui

Shadcn-inspired UI library.

## Components

- `Button` (variants: default, secondary, outline, ghost, destructive, link)
- `Card`, `CardHeader`, `CardContent`, `CardFooter`, `CardTitle`, `CardDescription`
- `Input`, `Textarea`, `Label`
- `DropdownMenu` primitives
- `Dialog` primitives
- `Table` primitives
- `Toaster` (sonner-based)

## Utilities

- `cn` – className merge helper
