# AI & Agents

This template is AI-ready. Use `AGENTS.md` for agent behaviors and `.cursor/rules` for guardrails.

## Recommendations

- Keep prompts and system rules in version control.
- Avoid hardcoding UI text; use `translations.ts`.
- Document tool usage and APIs in `docs/api`.

## Files

- `AGENTS.md` – Agent behaviors and safety
- `.cursor/rules` – Coding rules for AI assistants
- `.cursor/commands` – Common Cursor commands
